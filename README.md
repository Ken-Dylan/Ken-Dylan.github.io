# 烬旅 · Emberpath

一款可以直接在浏览器里玩的**肉鸽卡牌构筑游戏**（Roguelike Deckbuilder）。

王国烧尽之后，你从灰烬里醒来。带着一副残破的牌，向下穿过十层荒野，在余烬之王的王座前点燃最后一次火。

> 不需要安装、不需要联网、不需要构建。双击 **index.html** 即可开始。

---

1. 打开文件夹 C:\Users\19858\Desktop\games。

3. 点击「点燃余烬」开始一局。

如果浏览器询问是否允许本地文件运行脚本，选择允许即可。

## 核心玩法

- **路线选择**：地图有 11 层、29 个节点。每次只能前往与当前位置相连的节点，战斗、精英、事件、营火、商店、宝箱随路线变化。
- **回合制战斗**：每回合 3 点行动力、抽 5 张牌。点击卡牌打出；单体攻击在有多名敌人时需要点击目标。
- **敌人意图**：敌人头顶会显示下一步行动——攻击数值、格挡、增益或减益。根据意图决定进攻还是防守。
- **卡牌奖励**：战斗胜利后从 3 张牌中选 1 张（幸运币会变成 4 张）；也可以跳过，保持牌组精简。
- **遗物**：精英战、宝箱和商店都能获得遗物。遗物提供永久被动效果。
- **营火**：回复最大生命 30%，或永久升级一张牌。
- **商店**：购买卡牌、遗物，或花费金币移除一张牌、喝一碗热汤。
- **事件**：10 个手写事件，每个都有代价与回报不同的选择。
- **Boss**：余烬之王在生命低于 50% 时进入第二阶段。

## 内容规模

- 54 张卡牌（攻击 / 技能 / 能力，均可升级）
- 19 件遗物
- 14 种敌人 / 精英 / Boss
- 10 个随机事件、31 个事件选项
- 3 种精英战、多套敌人意图循环
- 分支路线、商店、营火、宝箱、卡牌奖励、Boss 二阶段
- 自适应桌面 / 平板 / 手机布局
- **程序化背景音乐**：标题 / 地图 / 战斗 / Boss / 终局五套氛围层，随场景自动切换
- 浏览器本地保存最佳评分、音乐与音效设置

## 小建议

- **牌组不是越厚越好**。每场战斗只抽 5 张，关键牌越容易抽到越好。
- 围绕一个核心机制构筑：力量、格挡、中毒、荆棘、抽牌引擎都可以单独成立。
- 营火优先升级核心牌；商店优先移除无用的基础牌。
- 精英战前确认血量与遗物，不要为了贪一个宝箱把命留在路上。
- 打 Boss 时留意「灭世余烬」的高额伤害；提前留好格挡。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| index.html | 页面入口 |
| styles.css | 全部界面样式与动画 |
| game.js | 游戏逻辑、卡牌 / 敌人 / 事件数据、渲染 |

游戏为纯原生 HTML / CSS / JavaScript，没有框架、构建步骤或外部资源请求。图标、角色和战斗背景都是内联 SVG / CSS 绘制。

## 技术备注

- 支持鼠标与触屏；手机端手牌区可横向滑动。
- 使用 localStorage 保存最佳评分、音乐与音效开关，不收集任何数据。
- 背景音乐与音效会在首次点击后启用，右上角可分别开关。
- 音乐由 WebAudio 实时合成：持续低音铺底、稀疏旋律、战斗鼓点与 Boss 强化层，不依赖任何音频文件或网络请求。
- 调试接口：打开浏览器控制台，可通过 window.Emberpath 查看当前状态。
